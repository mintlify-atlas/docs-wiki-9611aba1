All runtime configuration for the `fineract-provider` module lives in `fineract-provider/src/main/resources/application.properties`. Every `fineract.*` property supports an environment variable override expressed as `${ENV_VAR:default_value}`. Spring Boot's standard relaxed binding converts environment variables to property keys — uppercase `FINERACT_NODE_ID` maps to `fineract.node-id`. Properties not listed here (Spring Boot core, Tomcat, JPA, Liquibase, etc.) use their standard Spring Boot names.

<Info>
  All environment variable names follow the pattern `FINERACT_` + uppercase path segments joined with `_`. Where property names contain dots inside a segment (e.g., `fineract.datasource.connection-checkout-diagnostics.enabled`), hyphens are replaced with `_` for the env var.
</Info>

## Node Identity

| Property | Env Var | Default | Description |
|---|---|---|---|
| `fineract.node-id` | `FINERACT_NODE_ID` | `1` | Numeric node identifier used to distinguish nodes in a distributed Kafka/JMS topology. Each node should have a unique value. |

## Environment Variable Override Convention

Spring Boot's relaxed binding handles the mapping automatically. The rules are:

1. Dots (`.`) → underscores (`_`)
2. Hyphens (`-`) → underscores (`_`)
3. All characters → uppercase

So `fineract.remote-job-message-handler.kafka.bootstrap-servers` becomes `FINERACT_REMOTE_JOB_MESSAGE_HANDLER_KAFKA_BOOTSTRAP_SERVERS`.

Example Docker run with overrides:

```bash
docker run \
  -e FINERACT_NODE_ID=1 \
  -e FINERACT_HIKARI_JDBC_URL=jdbc:postgresql://db:5432/fineract_tenants \
  -e FINERACT_HIKARI_USERNAME=postgres \
  -e FINERACT_HIKARI_PASSWORD=secret \
  -e FINERACT_DEFAULT_TENANTDB_HOSTNAME=db \
  -e FINERACT_SECURITY_BASICAUTH_ENABLED=true \
  -e FINERACT_REMOTE_JOB_MESSAGE_HANDLER_SPRING_EVENTS_ENABLED=true \
  -p 8443:8443 \
  apache/fineract:latest
```
